# portaLumi kurzus metaadatok és rugalmas csomagok

Dátum: 2026-10-04

## Kurzus editor

### Szint
Opciók:
- nincs
- kezdő
- középhaladó
- haladó
- minden szint

### Időtartam
Nincs külön szerkeszthető kurzus-időtartam mező.

A rendszer a course_units duration mezőiből számolja ki.

### Kötelező sorrend
Egyszerű switch:

Bekapcsolva:
- Kötelező időrendi sorrend
- a leckék egymásra épülnek

Kikapcsolva:
- Moduláris

### Ajánlott napszak
Demo opciók:
- nincs
- közvetlenül ébredés után
- ébredés után 15–30 perccel
- reggel
- délelőtt
- ebéd körül
- napközben
- délután
- kora este
- este
- közvetlenül lefekvés előtt
- bármikor
- szükség szerint

### Formátum
Több érték választható dropdownból.

Demo opciók:
- videó
- hanganyag
- szöveg / cikk
- PDF / munkafüzet
- meditáció
- vezetett gyakorlat
- feladat
- kvíz
- kérdőív
- prezentáció
- élő / webinar
- interaktív / multimédia
- letölthető anyag

## Tartalom

Minden course_unit külön kapcsolóval jelölhető:

"Egyénileg is hallgatható"

Példa:
egy meditáció önmagában is ajánlható, akkor is, ha egy nagyobb kurzus része.

## Csomagok

A csomagok nem fix reggel + este párok.

A három demo:
- csak reggel
- csak este
- napi 3 blokk

A creator csomag editor az összes feltöltött kurzust látja, és ezekből állíthat össze új csomagot.
